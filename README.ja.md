## ✨ サーシャについて

長いピンクブラウンのウェーブ髪、カプセル型の目、大きな白いニット、茶色のスカートとローファー。どのポーズでもサーシャらしさを保っています。背景を透明にして生成し、白・黒の両方の背景で輪郭を確認しました。

[白黒背景で全動作を見る](preview/white-black-motion.mp4) · [全ポーズ](preview/contact-sheet.png) · [16方向の視線](preview/directions.png)

## 📦 同梱ファイル

- `pet.json` — サーシャのv2パッケージ設定
- `spritesheet.webp` — 軽量なロスレス透過スプライト
- `assets/spritesheet.png` — デコード後の画素が同じPNG版
- `preview/` — ポートレート、待機GIF、全動作動画、比較一覧
- `qa/` — 公開用のハッシュ値と検証概要
- `scripts/validate.py` — 再実行できるパッケージ検査

導入に必要なのは `pet.json` と `spritesheet.webp` の2ファイルです。他のペットの素材、非公開の生成入力、作業ログ、アカウント情報は含みません。

## 🚀 導入

**v2カスタムペットに対応したCodexデスクトップ版**を使用してください。この素材は11行構成です。旧式の9行専用ローダーには使用できません。

1. リポジトリのZIPをダウンロードして展開します
2. Codexホーム内の `pets/sasha/` に `pet.json` と `spritesheet.webp` を一緒にコピーします
3. 有効にしたい場合は、アプリのペット選択画面でサーシャを選びます

通常の配置先は `~/.codex/pets/sasha/` です。`CODEX_HOME` を設定している場合は、その配下の `pets/sasha/` を使います。既に `sasha` フォルダーがあれば停止し、意図して置き換える前にバックアップしてください。ファイルをコピーしても、選択中のペットは自動で変更しません。

WindowsとmacOS/Linuxのコマンドは[導入ガイド](docs/INSTALL.md)、確認済み・未確認の範囲は[対応状況](docs/COMPATIBILITY.md)に記載しています。

## 🎞️ 形式と検証

画像サイズは **1536 × 2288**。**192 × 208** のセルを **8列 × 11行**に配置しています。各行のコマ数は `6, 8, 8, 4, 5, 8, 6, 6, 6, 8, 8` で、未使用の15セルは透明です。

最初の9行は、待機・右移動・左移動・手振り・ジャンプ・失敗・入力待ち・作業中・確認です。最後の2行は時計回りの16方向の視線です。

公開PNGとWebPのRGBA画素は完全一致しています。[検証詳細](qa/validation.json)と[ファイルのハッシュ値](qa/assets.json)を参照してください。形式検査や画像の目視確認だけで、すべてのアプリ版での動作を保証するものではありません。

9状態・73コマ・16方向とループのつなぎ目を、各コマと再生設定から確認しました。コマの欠落・切れや、顔・手足の重大な破綻は見つかりませんでした。ただし、アニメーション品質の全面合格ではなく、次の課題が残っています。

- ジャンプから待機へ戻る際、髪の幅が急に細くなる
- 視線157.5°から180°の間で、頭・髪の輪郭が跳ねる
- 待機中の閉じ目が、再生設定上は約1.5秒続く
- 作業中・入力待ち・確認の区別が弱く、失敗がお辞儀に見えることがある

通常速度での連続再生の実視聴、Codexの実画面表示、ポインター追従・状態切替は未確認です。確認範囲は[対応状況](docs/COMPATIBILITY.md)を参照してください。

## 🛠️ パッケージの検査

Pythonと[uv](https://docs.astral.sh/uv/)がある環境で実行できます。

```sh
uv run scripts/validate.py
```

設定、ハッシュ、画像の寸法、使用・未使用セル、透過、不要なメタデータ、ローカル文書リンクを検査します。GitHub Actionsでも同じ検査を実行します。この検査は配布ファイルの整合性を確認するもので、アニメーション全体の目視QAを置き換えるものではありません。
